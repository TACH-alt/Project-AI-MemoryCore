## TikTok Photo-Mode Polish — Session 17, 2026-04-27

Reviewed Codex's live TikTok smoke-test results and made three targeted improvements:

### Decision: keep background audio for photo-mode posts

Photo-mode (carousel) TikTok posts have no downloadable video stream.
The previous behaviour: yt-dlp thumbnail fallback → silent image render.
The new behaviour: thumbnail fallback + audio fallback → image render with audio.

### Changes to process_shopee_video.py

- `no_media_message` for TikTok: clarified wording to mention photo-mode fallback.
- `cleanup_non_media_outputs`: now preserves `background.aac` alongside media files.
- `download_with_ytdlp`: when thumbnail fallback fires (photo-mode detected), immediately calls `download_tiktok_photo_audio` to grab the background music track.
- NEW `download_tiktok_photo_audio(url, raw_dir)`: runs `yt-dlp --format ba -x --audio-format aac --output background.%(ext)s`. Returns path to `background.aac` or `None`.
- `build_ffmpeg_command`: new `background_audio: Path | None = None` parameter. Image-source branch checks the parameter and adds a second `-i background.aac` input + `1:a` audio map when audio is present.
- `render_video`: detects `raw_path.parent / "background.aac"` and passes it to `build_ffmpeg_command` for image sources.
- `process_pending_rows`: detects photo-mode (TikTok URL + all raw files are images) and appends `(photo-mode post — cover thumbnail rendered with background audio)` to the status message.

### Changes to shoppee_video_frontend.py

- Product Link label hint updated: mentions Shopee/TikTok and shows TikTok short URL placeholder.
- New `#tiktokHint` span below the link input: purple text, hidden by default.
- New JS block: `updateTikTokHint()` listens on `input` + `change` events; shows the hint whenever the URL field contains `tiktok.com`.

### Photo-mode flow end-to-end

```
1. User pastes vt.tiktok.com URL → purple hint appears in frontend
2. Save + Download + Analyze →
   a. yt-dlp tries bv*+ba/b → fails (no video stream)
   b. download_tiktok_thumbnail_with_ytdlp → gets cover image
   c. download_tiktok_photo_audio → gets background.aac (if available)
   d. render_video → build_ffmpeg_command with -i image -i background.aac
   e. FFmpeg renders 8 s vertical-blur with background music + caption
   f. Status: "Downloaded 1 file(s); edited 1 video (photo-mode post — cover thumbnail rendered with background audio)"
3. analyze_row_record → analysis-result.md written with FFprobe metadata
```
