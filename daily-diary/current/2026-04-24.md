#### `process_shopee_video.py` — Render Mode System
Root cause of audio loss identified: `build_ffmpeg_command` had no `-map 0:a?` stream mapping for video sources.

Changes made:
- Added `RENDER_MODES = frozenset({"auto", "light", "vertical-blur"})`.
- Added `render_mode: str = "auto"` to `WorkflowConfig`.
- Rewrote `build_ffmpeg_command` with three-branch render logic:
  - `auto` → light for video, vertical-blur for images.
  - `light` → scale-to-fit + black padding + audio preserved.
  - `vertical-blur` → blur canvas background + audio preserved.
- All video branches now include `-map 0:a? -c:a aac` for audio pass-through.
- Added `--render-mode` CLI argument.
