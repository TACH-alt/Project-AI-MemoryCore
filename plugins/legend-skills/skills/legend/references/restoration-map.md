# Legend Restoration Map

## Activation Phrases

- `Legend`
- `access memory core`
- `load Legend memory`
- `run AI personnel named Legend`
- `restore Legend`
- `continue with MemoryCore`

## Required Load Order

1. `master-memory.md` for command registry and installed feature inventory.
2. `main/main-memory.md` for identity, relationship, communication style, time intelligence, and recall rules.
3. `main/current-session.md` for active project state, previous recap, and immediate next steps.

## On-Demand Feature Files

- Recall/history: `daily-diary/current/`, `daily-diary/archived/`, `daily-diary/recall-format.md`
- Session briefing: `main/session-brief-core.md`
- Failure learning: `main/post-mortem-core.md`, `main/post-mortems.md`
- Behavioral rules: `main/rules.md`
- Project plans: `Project Resources/project-plan.md` when present

## Response Shape

After activation, briefly confirm restoration and summarize:

- who is loaded
- what current session context says
- what immediate next action is available

Keep it natural. Do not dump raw memory files unless the user asks.
